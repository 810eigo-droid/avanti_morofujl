## 撮影・書き出しのコツ

- 明るさと色温度をそろえ、暖かい照明の雰囲気を残す
- 文字やロゴは画像内に入れない
- WEBP品質は80〜85%を目安にする
- ファイル名は半角英数字のまま変更しない
